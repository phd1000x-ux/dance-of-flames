## 1. 현재 진단 (코드 + 1차 플레이 데이터 기준)

| 영역 | 강점 | 약점 (근거) |
|---|---|---|
| 비행 | 상승·하강·경계 버그 수정 완료. 부스트 시 FOV와 카메라 거리가 변함 | 고속과 저속의 손맛 차이가 작음 |
| 전투 | 화염 이펙트, 건물 4단계 손상 표현, 붕괴 시 진동 | 처치가 하나씩 따로 보상됨(+1 kill). 체력 1200인 막사는 정지 상태로 약 16초 불을 뿜어야 무너짐. 그동안 발리스타 앞에 떠 있어야 함 |
| 적 AI | 발리스타 예고(레일 발광 + HUD 마커) | **실측: 순항 속도(44 m/s)로 직진하는 드래곤에게 볼트가 16발 중 2발만 명중.** 리드 계산식 `dist/95·0.85`가 실제 포물선 비행시간을 반영하지 못해 15~55 m 뒤로 빗나감. 예고에 반응하든 안 하든 결과가 같아서 "회피 학습"이 성립하지 않음. 1차 실험의 6/6 명중은 *저속* 비행에서만 나온 결과였음 |
| 난이도 | Story / Normal / Hard 3단계 | Hard는 피해량·체력·공격 빈도만 늘림. 숙련된 판단을 요구하는 차이가 없음 |
| UX | 단축키, 튜토리얼 E2E, 820×560 대응 | 화면 밖(뒤쪽) 발리스타는 경고가 전혀 없음. 회전 중인 포탑은 쿨다운 0 이후 마커가 사라지는데도 발사함 |
| 성장 | 상점 효과 표시, 유물 | 플레이 방식에 따른 보상 차이가 없음 |

## 2. 핵심 개선 방향

핵심 루프는 "급강하 → 경고 보고 회피 → 화염 스트레이프로 다수 제압 → 상승"입니다. 이 흐름의 각 고리를 실제로 작동하게 만듭니다.

| 우선 | 항목 | 변경 파일 | 기대 변화 | 완료 조건 (측정 가능) |
|---|---|---|---|---|
| P0 | 발리스타 정확 요격 조준 | `src/ai/EnemyManager.ts` (`boltAimPoint`) | 경고를 무시하면 맞고, 반응하면 피함 | `tests/ballista-dodge.test.ts`: 무회피 ≥75% 명중, 좌·우 선회 / 상승 / 하강 / Q·E 회피 각각 무회피 명중 수의 35% 이하, 좌우 차이 ≤2 |
| P0 | 경고가 실제 발사 시점까지 유지되고, 화면 밖 위협도 화면 가장자리에 표시 | `MissionScene.getBallistaThreats`, HUD, CSS | 뒤에서 날아오는 불합리한 피격 제거 | 실플레이에서 위협 마커 확인 |
| P0 | 난이도별 예고 시간 (Story 1.6 s / Normal 1.35 s / Hard 0.95 s) | `src/data/difficulty.ts` | Hard는 더 빠른 판단을 요구 | Hard에서도 회피가 유효함을 테스트로 확인 |
| P1 | 화염 연속 처치 (×N INFERNO) 표시와 코인 보너스 | `src/combat/FireStreak.ts`, `MissionScene`, `HudController` | 무리를 한 번에 쓸어내는 쾌감, 스트레이프 플레이에 보상 | 단위 테스트, 실플레이 중 표시 확인 |
| P1 | 목조 건물이 스스로 계속 타는 연소 | `src/world/BuildingSystem.ts` | 불을 붙이고 떠나는 플레이 가능, 정지 상태로 뿜는 시간 감소 | 막사 파괴에 필요한 *정지 상태 조준 시간* 감소 |
| P2 | 화면별 UI 점검 (820×560, 1280×800) | CSS | 겹침 0 | 스크린샷 |
